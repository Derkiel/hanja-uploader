개인정보처리방침

시행일: 2026년 9월 25일

"업로더"(이하 "이 도구")는 채널 운영자가 본인의 YouTube 채널에 영상을 올리기 위해 쓰는 개인용 도구입니다. 외부 사용자에게 서비스하지 않습니다.

1. 이용하는 Google 사용자 데이터

  • Google 계정 로그인으로 받은 OAuth 토큰 — 운영자 본인의 채널에 동영상과 썸네일을 업로드하고, 업로드한 동영상의 처리 상태를 확인하는 데에만 씁니다.
  • 요청 권한: https://www.googleapis.com/auth/youtube.upload, https://www.googleapis.com/auth/youtube.readonly

2. 저장과 보호

토큰은 운영자가 소유한 개인 서버의 접근 제한된 폴더(소유자만 읽기 가능)에만 저장하며, 로그나 화면에 기록하지 않습니다. 시청자나 다른 사람의 개인정보는 수집하지 않습니다.

3. 제3자 제공

Google 사용자 데이터를 판매하거나 제3자에게 제공·공유하지 않으며, 광고나 다른 목적에 쓰지 않습니다. 이 도구의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 보관과 삭제

토큰은 업로드 기능을 쓰는 동안만 보관합니다. 운영자는 언제든 Google 계정 권한 페이지에서 접근 권한을 철회할 수 있고, 철회하거나 이용을 중단하면 저장된 토큰을 삭제합니다.
