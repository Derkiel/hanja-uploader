개인정보처리방침 / Privacy Policy

시행일 / Effective date: 2026-09-26

1. 이 도구에 대하여 / About this tool

업로더(YouTube Lab)는 YouTube 채널 "한자왜그래"(@hanja.waegeurae)의 운영자가 자신의 채널에 영상을 올리고 관리하기 위해 직접 만든 개인용 도구입니다. 사용자는 채널 운영자 본인 한 명이며, 일반 사용자에게 공개하거나 제공하지 않습니다.

Uploader (YouTube Lab) is a private tool built by the owner of the YouTube channel "한자왜그래" (@hanja.waegeurae) to upload and manage videos on that channel. Its only user is the channel owner; it is not offered to the public or to any other user.

2. YouTube API 서비스 사용 / Use of YouTube API Services

이 도구는 YouTube API 서비스를 사용합니다. 이 도구를 사용하면 YouTube 서비스 약관에 동의하는 것이며, 데이터 처리는 Google 개인정보처리방침도 따릅니다.

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service, and data is also handled under the Google Privacy Policy.

3. 접근·사용하는 정보 / Information accessed and used

요청 권한 / Requested scopes: youtube.upload, youtube.readonly, youtube.force-ssl

  • 운영자 채널의 기본 정보(채널 ID·이름) — 올바른 채널에 올리는지 확인 / Basic channel information (channel ID, title) of the owner's channel, to confirm the destination channel.
  • 운영자가 만든 영상 파일·제목·설명·태그·썸네일 — 운영자 채널에 업로드 / Video files, titles, descriptions, tags and thumbnails created by the owner, uploaded to the owner's channel.
  • 운영자 채널에 올린 영상의 제목·설명·태그와 채널 설명 — 운영자가 수정할 때 / Title, description and tags of the owner's own videos and the channel description, updated when the owner edits them.

다른 사용자나 시청자의 개인정보는 수집하지 않습니다. 댓글·구독자·시청 기록 같은 다른 사람의 데이터에는 접근하지 않습니다.

No personal information of any other user or viewer is collected. The tool does not access other people's data such as comments, subscriber lists or watch history.

4. 저장과 보안 / Storage and security

Google 로그인으로 받은 인증 토큰은 운영자 본인의 서버(개인 네트워크 안의 컴퓨터)에만, 운영자만 읽을 수 있는 폴더에 저장합니다. 토큰은 로그·화면·외부 서비스로 내보내지 않습니다.

OAuth tokens obtained through Google sign-in are stored only on the owner's own server (a computer on a private network), in a folder readable only by the owner. Tokens are never written to logs, shown on screen, or sent to other services.

5. 공유 / Sharing

이 도구의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. / Use of Google user data complies with the Google API Services User Data Policy, including the Limited Use requirements.

이 도구가 다루는 정보는 누구에게도 판매·공유·이전하지 않습니다. 정보는 YouTube(Google)로만 전송됩니다(업로드·수정).

Information handled by this tool is not sold, shared or transferred to anyone. It is sent only to YouTube (Google) for uploads and edits.

6. 접근 해제와 삭제 / Revoking access and deletion

이 도구의 접근 권한은 언제든 Google 보안 설정의 서드파티 앱 권한 페이지에서 해제할 수 있습니다. 해제하거나 요청하면 서버에 저장된 토큰을 삭제합니다.

Access can be revoked at any time on the Google security settings page for third-party apps. On revocation or request, stored tokens are deleted from the server.

7. 쿠키 / Cookies

이 도구는 광고·추적용 쿠키를 쓰지 않습니다. / The tool uses no advertising or tracking cookies.
