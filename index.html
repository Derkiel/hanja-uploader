▶ YouTube 채널 한자왜그래(@hanja.waegeurae) 운영을 위한 개인용 도구입니다.

뉴스와 일상에서 만난 낱말의 한자를 풀어 주는 교양 영상(롱폼·쇼츠)을 만들고, 운영자 본인의 YouTube 채널에 업로드하고 제목·설명·태그를 관리하는 데 YouTube Data API를 사용합니다.

Uploader is a private tool for the YouTube channel 한자왜그래 (@hanja.waegeurae). It uses the YouTube Data API only to upload the owner's own videos to the owner's own channel and to manage their titles, descriptions and tags. It is not offered to any other user.

  • 사용자 / User: 채널 운영자 1명 (외부 사용자에게 제공하지 않음) / the channel owner only
  • 사용 권한 / Scopes: 동영상·썸네일 업로드(youtube.upload), 채널·동영상 정보 확인(youtube.readonly), 본인 동영상의 제목·설명·태그와 채널 설명 수정(youtube.force-ssl)
  • 이 도구는 YouTube API 서비스를 사용합니다 — YouTube 서비스 약관, Google 개인정보처리방침
